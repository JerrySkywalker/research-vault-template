# Canonical terminology

This directory holds reviewed cross-project terms. Use one descriptive Markdown file per term so its preferred English and Chinese forms change together. The [blank form](../templates/term.md) and [terminology guide](../docs/TERMINOLOGY.md) define the small contract. No term is canonical merely because it was mentioned in a project or inbox.

Find terms by filename, repository search, and ordinary links. A manually complete index is not required. Specialized vaults add their own reviewed terms; this public template ships no domain vocabulary.
